# 武汉理工大学失物招领网站

一个移动端优先的校园失物招领展示网站（课程结课作业）。

## 功能

- **双界面**：首页双入口——普通用户（浏览/发布/认领）与场所管理方（数据看板与信息管理），面向两类人群
- **两个模块**：捡到东西 / 需要找东西
- **两种浏览维度**：按物品分类（证件卡品类、电子数码类、学习用具类、生活用具类、其他类）或按区域（校区/楼层/片区，可配置），列表按时间降序
- **搜索**：精确搜索 + 可开关的模糊搜索（支持口语化描述）
- **详情页**：失物图片（最多 3 张轮播）、描述、联系方式一键复制、评论区
- **AI 拍照即发布**：上传图片后自动识别主色调、推荐名称、生成描述（演示版，可替换为大模型视觉 API）
- **智能撮合**：捡到/寻找双向语义匹配（同义词 + 品类 + 区域 + 时间窗打分），自动推荐可能匹配的信息
- **模拟发布**：表单填写 + 图片上传，发布后置顶显示
- **隐私保护**：证件类物品上传图片时自动提醒，并提供涂抹打码工具，确认遮挡后才能发布
- **认领机制**：详情页认领验证提示，标记已找到后页脚统计实时更新
- **管理端**：找回率 KPI、失物热力地图（平面 SVG / 立体楼层堆叠两种模式）、品类与时段分布、规则引擎防丢建议、待认领信息管理（标记已找到/下架）、滞留预警与招领公告（民法典第318条）、数据明细
- **场景可配置**：改 `js/config.js` 即可切换场景（校园/商场/景区示例见 `js/config-examples.js`），地图随配置一起切换（"地图即配置"）

## 技术说明

纯原生 HTML + CSS + JavaScript，无框架、无构建工具、无外部依赖，完全离线可用。数据保存在浏览器 localStorage 中模拟后端（首次打开自动写入示例数据）。双击 `index.html` 即可本地运行，也可部署到 GitHub Pages。

## 目录结构

```
├── index.html        # 页面骨架
├── css/style.css     # 全部样式（淡蓝主题、移动优先）
└── js/
    ├── data.js       # 校区/分类常量与示例数据
    ├── store.js      # localStorage 数据读写层
    └── app.js        # 路由与页面渲染逻辑
```

## 更新网站

改动文件后，双击 `更新网站.bat` 即可自动上传，约 1 分钟后线上生效。
